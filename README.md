# 自宅の整理整頓（Home Organizer）

自宅の収納場所と所持品を登録し、あとから検索できる個人向けのスマートフォン対応Webアプリです。

- **アプリを開く：** https://galette-art.github.io/home-organizer/
- **主な対象：** Android / Chrome などのモバイルブラウザ

## 主な機能

### 1. 「探す」— 所持品の検索
- 品名を入力して登録済みの物を検索できます。
- タグや部屋を使って検索結果を絞り込めます。
- 検索結果から物の詳細を開き、配置・タグ・メモ・写真を確認できます。
- 物の詳細画面から編集・削除ができます。

### 2. 「場所」— 家の中の収納場所を管理
- 部屋、収納、棚、引き出しなどを階層構造で登録できます。
- 下位の場所を追加して、家の中の収納を階層的に整理できます。
- 収納場所には名前と写真を設定できます。
- 場所の追加・編集・削除に対応しています。下位の場所を含む削除操作もあります。
- 編集モードで場所をまとめて選択して削除できます。
- 同じ階層内の場所をドラッグ＆ドロップで並べ替えできます。
- 場所の階層を開くと、画面上部にパンくずリストが表示されます。「部屋」や上位の場所をタップして、その階層へ戻れます。

### 3. 「追加」— 所持品の登録
- 品名と配置を入力して物を登録できます。
- 配置は「部屋 → 収納 → 棚・引き出し」のように、選んだ階層に応じて順番に選択できます。
- 複数のタグ、自由記入のメモ、写真を登録できます。
- 「この場所に続けて登録」を使うと、登録後も同じ配置を保ったまま、次の物を入力できます。
- タブを移動しても、追加フォームに入力中の内容はそのまま保持されます。
- タグは複数選択でき、新規追加・名前の編集・削除・並べ替えに対応しています。

### 4. 画面操作・デザイン
- 下部のナビゲーションから「探す」「場所」「追加」を切り替えられます。
- タッチ画面では、画面を左右にスワイプしてメインタブを切り替えられます。
- スマートフォンでの使用を想定した、カフェ風の配色とカード型の画面デザインです。
- 対応ブラウザでは、ホーム画面に追加してアプリに近い表示形式で起動できます（PWA）。

## 公開範囲・プライバシー

- このREADMEとアプリのソースコードは、GitHub上で公開されています。記載内容は誰でも閲覧できる前提で管理してください。
- アプリの所持品・場所・タグなどの情報は、使用中のブラウザの **localStorage** に保存されます。
- 写真データはブラウザの **IndexedDB** に保存され、所持品や場所のデータには写真の参照情報が保存されます。
- Googleログイン後にクラウド同期を有効にすると、所持品データと写真を同じアカウントの端末間で同期できます。ログインしていない場合は端末内に保存されます。
- ただし、ブラウザや端末そのものの安全性までは保証できません。パスワード、鍵情報、金融情報など、特に機密性の高い情報の保存は避けてください。
- ブラウザのサイトデータを消去したり、端末・ブラウザの状態が変わったりすると、保存データを失う可能性があります。大切なデータを登録する際はご注意ください。
- 現在のService Workerは登録処理を行いますが、アプリのファイルをキャッシュしてオフライン動作させる実装はありません。**オフラインでの利用は保証されません。**

## 技術構成

- **index.html**：画面、スタイル、アプリの処理
- **manifest.json**：PWA名、起動URL、表示形式、アイコン設定
- **service-worker.js**：Service Workerの登録先
- **icons/**：アプリアイコン

HTML・CSS・JavaScriptを中心とした構成で、GitHub Pagesから公開しています。現行アプリはリポジトリ直下の **index.html** を使用します。

## 現在の仕様・制約

- 主に1人が1つのブラウザ内で使うことを想定しています。
- Googleログイン、クラウドバックアップ、自動同期、クラウドバックアップからの復元に対応しています。Supabase / Google OAuthの設定状況やネットワークによって利用できない場合があります。
- 写真の保存容量やブラウザの保存領域は端末・ブラウザの制限を受けます。
- ホーム画面への追加方法や表示は、端末・ブラウザによって異なります。
- READMEの記載はコード上の実装を整理したもので、すべての端末・ブラウザでの動作試験を保証するものではありません。

## 開発方針

既存機能への影響をできるだけ避けながら、実際の家庭内で使いやすいように改善を重ねます。機能追加や修正では、現在の「探す」「場所」「追加」の基本操作と、登録データの保持を優先します。


## Googleログイン・クラウド同期（開発版）

このブランチには、Google OAuthによるログイン、Supabaseへのデータ保存、写真ストレージ、自動同期、日次バックアップの実装を追加しています。**実際にクラウド同期を有効にするには、所有者がSupabaseとGoogle OAuthを設定する必要があります。**設定前は既存の端末内保存とJSONバックアップのみ利用できます。

### セットアップ

1. Supabaseでプロジェクトを作成します。
2. SupabaseのSQL Editorで `supabase-setup.sql` を実行します。これはユーザー単位のRLSポリシーと非公開写真バケットを作成します。
3. SupabaseのAuthenticationでGoogleプロバイダーを有効にし、Google Cloud ConsoleでOAuthクライアントを作成します。Supabaseが表示するCallback URLをGoogle側へ登録します。
4. SupabaseのAuthentication URL設定に、公開アプリURLと開発用URLを許可リダイレクト先として登録します。
5. `supabase-config.js` の `url` と `anonKey` を実際のSupabase Project URLと公開用 anon/publishable keyに置き換えます。**service_roleキーは絶対に設定しないでください。**
6. 開発環境で、既存データのJSONバックアップを先に書き出してからGoogleログインをテストします。

### 同期・移行時の注意

- 初回ログインでクラウドデータが存在しない場合、現在の端末データをクラウドへ保存します。
- すでにクラウドデータがある場合は、確認ダイアログで「OK＝クラウドから復元」「キャンセル＝端末内データを維持し、今回は同期しない」を選択します。必要な場合は、設定の「クラウドにバックアップ」で端末内データを送信します。誤操作防止のため、選択前に端末内バックアップを書き出してください。
- 写真は非公開のSupabase Storageへアップロードし、ユーザーIDで分離します。
- 日次バックアップは同期・バックアップ操作時に保存されます。自動同期は端末でアプリが動作している間に行われ、ブラウザを閉じた後の即時同期は保証されません。
- Supabaseの設定・認証プロバイダー・実機での複数端末テストが完了するまでは、クラウド同期が本番運用可能とみなさないでください。
